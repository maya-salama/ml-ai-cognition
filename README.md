# ML-Powered Evaluation of Generative AI & Student Cognition

This project extends my research on generative AI use and student cognitive development by using machine learning to investigate whether generative AI use, academic behaviors, and student characteristics can predict student-reported analytical and critical-thinking outcomes.

## Project Goals

- Explore and clean the UCUES 2024 dataset
- Build baseline statistical and machine learning models
- Compare model performance
- Identify important predictors of cognitive outcomes
- Evaluate whether generative AI variables improve prediction
